# 2026-11-09

## 新增 GitHub Actions 发布流水线

- 文件：`.github/workflows/release.yml`（tag `v*` 触发发布；`workflow_dispatch` 只打包校验不发布）
- 打包范围：仅 `Modules/` 目录**内容**，先 `cd Modules` 再 zip，zip 根目录直接是 `module.prop`。
- 资产名规则：`<module.prop id>_<version>_<VARIANT>.zip`，`VARIANT=apk-embedded`，即
  `clouddrive2_ksu_magisk_v1.1.6-r14_apk-embedded.zip`。
- 发布时序：`gh release create --draft` → `gh release upload` → `gh release edit --draft=false`，
  保证 GitHub 自动生成的 Source code (zip/tar.gz) 与模块包同一时刻生成；开跑前删除同标签残留草稿，
  失败时也删草稿，避免残留草稿导致重跑失败。
- 一致性校验（打标签后立即失败，避免发布后无法回滚）：
  1. 标签名 == `module.prop` 的 `version`；
  2. `update.json` 的 version / versionCode / zipUrl 末段必须匹配本次资产；
  3. `module.yaml` 的 `id` 与 `release.assetPattern` 必须匹配。
- 预发布判定不能用官方模板的「含 `-` 即 prerelease」——本仓库版本号都是 `vX.Y.Z-rNN`，
  改为 `=~ -(rc|alpha|beta|pre|dev)`。
- 已知注意点：`module.yaml` 的 `release.assetPattern` 目前写死为 r14 的完整文件名，下个版本必须同步改；
  建议改成 `clouddrive2_ksu_magisk_*_apk-embedded.zip`。
- 官方模板参考：`KernelSU-Modules/example-module/.github/workflows/release.yml`
  （checkout 固定 SHA `3d3c42e5aac5ba805825da76410c181273ba90b1` = v7.0.1）。
- 仓库换行：git 对象中为 LF（`core.autocrlf=true`，工作区显示 CRLF），CI 检出为 LF，无需额外处理。

## 新增 .gitattributes 固定换行符

- 起因：GitHub Desktop 提示 "This diff contains a change in line endings from 'LF' to 'CRLF'"，
  是本地 `core.autocrlf=true` 导致的整文件假 diff。
- 方案：仓库级 `.gitattributes` → `* text=auto eol=lf`，`*.apk/*.png/*.jpg/*.webp/*.zip` 标 `binary`。
- 已验证：`git check-attr` 文本文件 eol=lf、apk/png `text: unset`；`git status` 未产生任何已有文件的改动。
- 备注：`.workbuddy/` 目前是未跟踪状态，若不想它出现在提交列表需另加 `.gitignore`（尚未创建）。
